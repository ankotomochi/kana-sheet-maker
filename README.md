# Kana Sheet Maker

Free printable hiragana, katakana and kanji writing-practice sheets, made by [OmochiWorks](https://omochiworks.etsy.com).

- Numbered stroke order for every kana
- Grey trace copies and a dashed cross guide
- A4 or US Letter, print or save as PDF
